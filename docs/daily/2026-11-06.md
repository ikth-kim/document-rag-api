# 2026-11-06 환경 세팅

## 새로 안 것
- app/__init__.py는 폴더를 패키지로 표시하는 파일이다.
- FastAPI는 지정한 파일에서 app 변수를 찾아 서버를 띄운다.

## 오류 : Could not find FastAPI app
- 증상 : dev 서버 실행 시 "Colud not find FastAPI app in module"
- 원인 : app/main.py에 코드를 붙여 넣지 넣고 저장(Ctrl+S) 하지 않아서, 디스크의 파일이 비어 있었고 FastAPI가 app 변수를 찾지 못함
- 해결 : 저장 후 재실행
- 배운 점 : 서버는 에디터 화면이 아니라 디스크에 저장된 파일을 읽는다. VS Code 탭의 ● 표시가 저장 전 신호
